# Tâche C — Fin de formulaire

Formulaire « Paramètres du compte » d'une application : deux ou trois champs (nom affiché, e-mail, langue) puis la **zone d'actions de fin de formulaire**, qui doit permettre :

- **enregistrer** les modifications ;
- **annuler** ;
- **supprimer le compte** (action destructive et irréversible).

Produis l'écran complet. C'est toi qui décides de la hiérarchie visuelle et du placement des trois actions.
