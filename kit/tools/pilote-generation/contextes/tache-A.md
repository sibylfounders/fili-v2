# Tâche A — Toolbar de collection

Écran « Factures » d'une application de gestion : une liste de factures (8 lignes fictives : numéro, client, montant, statut) surmontée d'une **barre d'outils** portant cinq actions :

- créer une facture ;
- exporter ;
- filtrer ;
- supprimer la sélection ;
- paramètres d'affichage.

L'écran doit être complet et réaliste (titre, toolbar, liste). C'est toi qui décides de la hiérarchie visuelle des cinq actions.
