# Fili — Kit de création (dépôt de travail et de sauvegarde)

*Créé le 23 août 2026.* Ce dépôt existe parce que le code du kit a été perdu
deux fois : il n'avait jamais été versionné. Tout ce qui a survécu est ici ;
tout ce qui se construit désormais se committe ici.

## Les dossiers

- **etalon/** — le générateur de l'Auteur, « Échelle Semantic Rhythm »
  (copie du 11 août). C'est la référence : le kit se calcule sur elle,
  jamais l'inverse.
- **atelier/** — le premier kit, « l'atelier » : les 9 versions de
  « Sibyl Scale — générateur d'échelle de surfaces » (9–10 août), de la
  plus ancienne (`sibyl-scale.html`) à la plus récente (`sibyl-scale_8.html`).
- **banc/** — le banc de conformité (3 versions, 9 août) : la page qui
  audite un écran avec les 9 invariants.
- **audit/** — les deux moteurs sauvés au projet Claude :
  `moteur-audit.mjs` (les 9 invariants, lecture du rendu) et
  `overlay-audit.mjs` (le panneau de rapport à poser sur n'importe quelle page).
- **demo/** — `demo-tokens.html` : la démo « deux composants, un seul jeu de
  décisions », d'avant l'alignement sur l'échelle de l'Auteur.
- **page/** — la page « réglez et téléchargez ». Perdue le 11 août avec sa
  session ; elle se reconstruit ici. Voir `page/A-RECONSTRUIRE.md`.

## Règles du dépôt

- Une amélioration = un commit. Le message dit ce que l'œil verra changer.
- Les originaux restent dans Téléchargements ; ici vivent les copies de travail.
- Sauvegarde distante : GitHub privé, à brancher (décision d'Auteur du 23 août).
