# Tâche B — Groupe d'actions par élément d'une collection

Écran « Membres de l'équipe » d'une application d'administration : une liste de huit membres (nom, e-mail, rôle, dernier accès), avec :

- une action globale : **inviter un membre** ;
- sur **chaque ligne**, un groupe de quatre actions : **voir le profil** (fréquente), **modifier le rôle**, **réinitialiser le mot de passe** (rare), **désactiver le compte** (destructive, rare).

L'écran doit être complet et réaliste. C'est toi qui décides, pour l'action globale comme pour le groupe de chaque ligne, de ce qui est visible en pleine présence, ce qui est réduit, ce qui est replié — et de la hiérarchie entre tout cela.
