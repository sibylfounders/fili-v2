# Consigne de sortie (identique dans toutes les conditions, mot pour mot)

Produis **un seul fichier .jsx complet** :

1. les imports depuis `'@fili/react'` (et `'@fili/react/icons'` si besoin) ;
2. un composant React exporté par défaut qui implémente la tâche demandée ;
3. **en fin de fichier**, un bloc de commentaire :

```
/* JUSTIFICATION
- <décision de hiérarchie ou de choix de composant> → <fondement cité : identifiant de règle ou de tension si tu en connais un (ex. SUJET-R12, T-001), sinon le principe nommé en une phrase>
- …
Si deux règles ou principes pertinents entrent en conflit sur une décision : nomme le conflit et justifie l'arbitrage rendu.
*/
```

Chaque décision de hiérarchie (quelle action domine, quel poids pour chaque action, bouton vs lien, surface cliquable ou non, placement d'une action destructive…) doit avoir sa ligne dans JUSTIFICATION.

Écris le fichier demandé à l'emplacement indiqué. N'écris rien d'autre.
